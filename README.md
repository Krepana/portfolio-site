# Portfolio Website – Ana Nika

Welcome to my personal portfolio website! This project showcases my skills, experience, and projects as a marketing communications professional with a creative edge in digital strategy and content creation. It is a project for my Graduation Course called "Web Programming".

## 🚀 Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **AOS Animations:** Scroll animations to enhance user engagement.
- **Custom Loader:** Intro animation that improves user experience on page load.
- **Modal Projects Gallery:** Interactive modals for detailed project previews.
- **Downloadable CV Button:** Easy access for recruiters or collaborators to download my resume.
- **Creative About Section:** Includes dynamic GIF and layout design.

## 🛠️ Built With

- **HTML**
- **CSS**
- **JavaScript** – for modals, loader, and interactive elements
- **AOS (Animate On Scroll Library)** – [AOS Documentation](https://michalsnik.github.io/aos/)

## 📝 How to Use

1. Clone the repo:  
   `git clone https://github.com/yourusername/your-repo-name.git`

2. Open the project in VS Code or your editor.

3. Open `index.html` in your browser or use Live Server extension for preview.

## 📦 Deployment

This site can be easily hosted on GitHub Pages:

1. Push your code to GitHub.
2. Go to your repository settings.
3. Enable GitHub Pages under Pages section and select the root directory.
